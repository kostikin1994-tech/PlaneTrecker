# PlaneTrecker

**PlaneTrecker** — консольное приложение для поиска и отслеживания самолётов по выбранной стране.

Проект получает географические координаты страны через OpenStreetMap Nominatim, а затем запрашивает информацию о самолётах через OpenSky Network API.

## Возможности

- Поиск самолётов по названию страны.
- Получение информации о самолётах:
  - позывной;
  - страна регистрации;
  - скорость;
  - высота.
- Сравнение самолётов по скорости и высоте.
- Сортировка самолётов по скорости и высоте в порядке убывания.
- Вывод Top N самых быстрых самолётов.
- Фильтрация по стране и диапазону высоты.
- Сохранение информации о самолётах в JSON.
- Удаление самолётов из JSON по позывному.

## Установка и запуск

1. Клонируйте репозиторий:

```bash
git clone <ссылка-на-репозиторий>
```

2. Перейдите в папку проекта:

```bash
cd PlaneTrecker
```

3. Установите зависимости:

```bash
poetry install
```

4. Запустите приложение:

```bash
poetry run python main.py
```

## Архитектура

В проекте используются принципы объектно-ориентированного программирования.

- **Aircraft** — модель самолёта с атрибутами и валидацией данных.
- **AircraftProvider** — абстрактный интерфейс для получения данных о самолётах.
- **APIAdapter** — взаимодействие с внешними API.
- **AircraftConverter** — преобразование полученных данных в объекты Aircraft.
- **JSONSaver** — сохранение и удаление информации о самолётах в JSON.

В проекте применяются принципы SOLID:

- **SRP** — разделение ответственности между моделью, преобразователем данных, API-адаптером и хранилищем.
- **OCP** — возможность добавления новых реализаций абстрактного интерфейса AircraftProvider без изменения контракта получения данных.
